# Result files

The trained runs behind the tables of the paper, one directory per task and run:

```
results/<task>/<model>_s<seed>/result.json     test metrics (test, test100, zero-shot sets), parameters, timing, diagnostics
results/<task>/<model>_s<seed>/config.json     the trainer arguments (args), the model configuration, the data summary
results/<task>/rhmp_s<seed>/best.pt            the RHMP checkpoint selected on the validation R2 (RHMP runs only)
results/evaluations/                           zero-shot, rotation, bootstrap and ablation evaluations (README there)
results/RESULTS.md                             the tables, generated by scripts/collect_results.py
```

| directory | task (code) | runs |
|---|---|---|
| `ns_vorticity/` | NS vorticity on a stretched periodic grid (RHMP `T1gml_mean`, baselines `T1g`) | RHMP and 12 baselines (incl. FNO), seeds 42, 1, 2 |
| `torus_transport/` | anisotropic transport on a torus (`T2a`) | RHMP and 11 baselines, seeds 42, 1, 2 |
| `ellipsoid_flow/` | ellipsoid surface flow (RHMP `T3g`, baselines `T3`) | RHMP and 11 baselines, seeds 42, 1, 2 |
| `maxwell_magnetostatics/` | nonlinear anisotropic magnetostatics (`MXA`) | RHMP and 11 baselines, seeds 42, 1, 2 |
| `wilson_loop/` | U(1) Wilson loop (`T6`) | RHMP and 11 baselines, seeds 42, 1, 2 |
| `yang_mills/` | SU(2) Yang-Mills (`T7`) | RHMP and 11 baselines, seeds 42, 1, 2 |
| `yang_mills_face/` | SU(2) Yang-Mills with the field strength on the faces (`T7f`) | RHMP, seed 42 |
| `airfrans_pressure/` | AirfRANS pressure on body-fitted meshes (RHMP `AFPi0`, baselines `AFP`) | RHMP and 10 baselines, seeds 42, 1, 2 |

253 runs; `python3 scripts/train_paper_models.sh` lists the command of every one (the `args` of each `config.json`).
`result.json["test100"]` holds the four metrics of the paper's tables (SSIM, Pearson, NRMSE, R2 on the first 100 test
samples), `result.json["test"]` the full test split; the NS runs also store the zero-shot grids (`zs_U32`, `zs_G2`,
`zs_U64`, `zs_G1rot`) and the Maxwell runs the zero-shot sets (`ood15`, `heldout`, `fine`, `coarse`, each also on
`test100`).  The `gpu` field names the GPU a run was trained on (RTX PRO 6000 Blackwell or RTX A6000); re-evaluating a
checkpoint on another GPU model reproduces its metrics to about 1e-6 (TF32 rounding), see `scripts/eval_checkpoint.py`.

A checkpoint is re-evaluated with

```bash
python3 scripts/eval_checkpoint.py results/torus_transport/rhmp_s42            # test and test100 against result.json
python3 -m rhmp.train --task T2a --eval-ckpt results/torus_transport/rhmp_s42 --out runs/eval   # the trainer's evaluation path
```

and loaded in Python with `RHMP.from_checkpoint("results/torus_transport/rhmp_s42/best.pt", map_location="cpu")`.
